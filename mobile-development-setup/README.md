# Mobile Development Setup

## Overview
This repository contains the setup instructions for establishing a mobile development environment using **React Native** and **Expo**. The goal is to ensure a seamless and efficient development process.

## Prerequisites
Before proceeding, ensure you have the following installed:

- **Node.js LTS** ([Download here](https://nodejs.org/))
- **VS Code** (Recommended IDE) ([Download here](https://code.visualstudio.com/))
- **macOS, Linux, or Windows** (Compatible OS)
- **Expo Go** (Installed on your physical device: Android or iOS)

## Why Expo Go?
Expo Go simplifies mobile development by allowing you to run React Native applications on your physical device without the need for an emulator. This saves computational resources and streamlines the testing process.

## Installation Steps
### 1. Install Expo Go on Your Device
- **Android:** Install from the [Google Play Store](https://play.google.com/store/apps/details?id=host.exp.exponent).
- **iOS:** Install from the [Apple App Store](https://apps.apple.com/us/app/expo-go/id982107779).

### 2. Set Up Expo Account
- Open the **Expo Go** app.
- Sign up or log in to your Expo account.
